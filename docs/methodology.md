# Methodology

## Metric scopes
Operational snapshot: BNPB dashboard, 29 Sep 2026.
Situation snapshot: BNPB report for 28 Sep 2026, published 29 Sep 2026.
Province comparison: uniform cumulative burned area through 9 Aug 2026.
Hotspot concentration: BMKG published windows with high-confidence hotspot counts.

## Relevance validation
1. Search the official source domain by topic keywords.
2. Discover candidate URLs using robots.txt/sitemap, internal links, and site-restricted search.
3. Fetch candidates.
4. Score title, URL, and page-text matches.
5. Accept only when the score reaches the configured threshold.
6. Otherwise use the configured fixed reference URL.

## Interpretation
Hotspots are satellite detections, not automatically equivalent to confirmed fires.
Fire spots and burned area are different measures with different time windows.
The map highlights six national priority response provinces; it does not imply other provinces cannot experience karhutla.
